# Santa Pola Sub-2

A 15-week half-marathon training plan to break **2:00:00** at the 35ª Mitja Marató Internacional Vila de Santa Pola — Sunday 24 January 2027.

A single self-contained `index.html`: a pace calculator, a week-by-week schedule with loggable runs and periodised strength sessions (ticks and logs saved in your browser), and race-day pacing. No build step, no dependencies.

**Live:** https://sdivelbiss.github.io/santa-pola-sub2/

To change it, edit `index.html` and push — GitHub Pages redeploys automatically.
